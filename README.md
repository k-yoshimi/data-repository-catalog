# ISSP Data Repository catalog (preview)

Static site published at https://k-yoshimi.github.io/data-repository-catalog/.

This repository only holds the built site. It is generated by
[k-yoshimi/repo-catalog](https://github.com/k-yoshimi/repo-catalog)
(`scripts/build-isspns.sh`) from the public projects on the ISSP GitLab and
the data repository registry, and is replaced on every update.
