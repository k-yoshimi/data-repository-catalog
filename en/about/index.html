About this site

About this catalog

A catalog of the data published in the ISSP Data Repository, listed so that it is easy to find. Search by keyword and narrow the list by the paper's year and authors, whether there is a DOI, and more.

The ISSP Data Repository

A service for publishing research data, run by the Institute for Solid State Physics (ISSP), the University of Tokyo, since fiscal year 2020. The data are published as repositories on the ISSP GitLab. See the data repository portal for details.

Using the data

Use each dataset under the license shown on its page.

How to cite

When you publish work that uses the data, cite the corresponding paper and the URL of the data's page. The "Paper and citation" section of each page has buttons to copy the citation and BibTeX.

Where the information comes from

  • The registration details, and the repositories' public information on the ISSP GitLab
  • Citation counts, paper details and keywords: OpenAlex
  • BibTeX: doi.org

The information is updated regularly; the last update is shown at the bottom of each page.

Apply from the Register page.
