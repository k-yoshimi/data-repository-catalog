Overview

This repository contains model parameters for the tight-binding description of the ambient-pressure Dirac electron state in α-(BETS)₂AuCl₂. These parameters are constructed to reproduce the quasi-three-dimensional massive Dirac semimetal electronic structure identified by first-principles calculations including spin–orbit coupling, and are intended for reuse in theoretical and computational studies.

README

Dataset for α-(BETS)₂AuCl₂: Electronic Structure and Physical Properties

Project Overview

This dataset supports a theoretical and experimental study on the organic conductor α-(BETS)₂AuCl₂, where BETS stands for bis(ethylenedithio)tetraselenafulvalene. The study involves x-ray diffraction measurements, ab initio calculations using Quantum ESPRESSO, downfolding calculations using RESPACK, Wannier function calculations using Wannier90, and many-body calculations using H-wave.

About

This repository provides a comprehensive dataset related to the theoretical and experimental study of the organic conductor α-(BETS)₂AuCl₂. The data includes:

  • Crystal structure data (CIF format)
  • Experimental electrical resistivity measurements
  • Ab initio electronic structure calculations (with and without spin-orbit interaction)
  • Wannier function calculations
  • Fermi surface and band dispersion analysis

Non-SOI Directory Structure

The non-soi directory contains calculations without spin-orbit interaction:

  • qe/ (Quantum ESPRESSO):

    • scf_relax.in, scf_relax.out: Input/output files for relaxation calculation
    • scf.in, scf.out: Input/output files for SCF calculation
    • band.in, band.out: Input/output files for band calculation
    • bands.in, bands.out: Input/output files for bands calculation
    • nscf.in, nscf.out: Input/output files for NSCF calculation
    • aucl2.band.gnu: Band structure data for plotting

  • respack/ (RESPACK):

    • respack.in: Input file for RESPACK
    • calc_wan.out: Output file for Wannier calculation
    • dat.iband: Output file of bands obtained by Wannier calculation
    • dir-intW/: Directory containing bare and screened long-range Coulomb interactions
    • dir-model/: Directory containing effective models

  • wannier90/ (Wannier90):

    • aucl2.win: Wannier90 input file
    • aucl2.wout: Wannier90 output file
    • aucl2_hr.dat: Hamiltonian in Wannier basis
    • pw2wan.in, pw2wan.out: Interface files between QE and Wannier90

  • hwave/ (H-wave):

    • input.toml: H-wave input file
    • fermi_energy.dat: Calculated Fermi energy
    • band_dispersion.pdf: Band dispersion plot
    • FermiSurface_mod_orb*.pdf: Fermi surface plots for each orbital
    • output/: Output files and plots

Experimental Data

The experiments directory contains temperature-dependent electrical resistivity measurements:

  • Measurement conditions:

    • Temperature range: ~2 K to 300 K
    • Applied magnetic fields: 0, 2.5, 5, 9 kOe

  • Data files:

    • BETS2AuCl2_in-plane.csv: In-plane resistivity (ρ∥)
    • BETSAuCl2_out-of-plane.csv: Out-of-plane resistivity (ρ⊥)

Usage Instructions

To use this data, you will need the following software:

  • Quantum ESPRESSO
  • RESPACK
  • Wannier90
  • H-wave
Steps to Reproduce Calculations

  1. Set Up Quantum ESPRESSO:

    • Use the provided .in files for SCF, relaxation, band, and NSCF calculations.
    • Run the calculations using Quantum ESPRESSO with the appropriate input files.
    • For SOI calculations, ensure you use fully relativistic pseudopotentials.

  2. Run Wannier90 Calculations:

    • Use the pw2wan.in file to interface with Quantum ESPRESSO.
    • Run Wannier90 using the aucl2.win input file.
    • Obtain the Wannier Hamiltonian (aucl2_hr.dat).

  3. Run RESPACK Calculations (Non-SOI only):

    • Use the respack.in file to set up RESPACK.
    • Perform the downfolding calculations and obtain the effective models.

  4. Run H-wave Calculations:

    • Use the input.toml file to configure H-wave.
    • Calculate the Fermi surface and band dispersion.

  5. Analyze Results:

    • Use the output files to analyze the electronic structure and band calculations.
    • Refer to the .gnu files for plotting the band structures with gnuplot.
    • Compare non-SOI and SOI results to understand the effect of spin-orbit coupling.
