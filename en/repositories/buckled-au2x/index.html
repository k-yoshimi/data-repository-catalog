README

Electronic band structure change with structural transition of buckled Au$_2$X monolayers induced by strain

About

This study investigates the structural transitions of $\eta \leftrightarrow \theta$ and the changes in electronic band structures of Au$_2$X (X=S, Se, Te, Si, Ge) and Au$_4$SSe induced by strain. This database provides the input files and the results of the DFT calculations by OpenMX.

Usage

  • Install Database

    • Using git

      git clone https://isspns-gitlab.issp.u-tokyo.ac.jp/masahiro.fukuda/buckled-Au2X.git

    • On browser Click the download button of this project.

  • Data info

    • This database includes input files and results of $\eta$- and $\theta$-Au$_2$X (X=S,Se,Te,Si,Ge) and Au$_4$SSe by DFT.
      • cddf : optical conductivity, dielectric function.
      • e_band : electronic band structure.
      • e_band_analysis : decomposition of electronic band.
      • energy_curve : energy curve for lattice length.
      • opt : geometrical optimization.
      • ph_band: phonon band dispersion.
      • ph_band_CCL: phonon band dispersion using partition method.
      • reoptRF: re-optimization for phonon band calculation.
      • reoptRFC5: cell re-optimization for phonon band calculation.
      • shift_Satom : shift S atom far from Au layer for electronic band analysis.
      • neb: Nudged Elastic Band calculation from $\theta$-phase to $\eta$-phase.
