Overview

The exact diagonalization method is often used as a verification data for comparison with other methods, since it returns exact results under the specified system size and model. Therefore, the existence of a database (DB) for various models based on a uniform data standard is expected to be useful for the development of the field of condensed matter physics. COMPUTATION ARchive of Exact Diagonalization (COMPARED) is a DB for quantum lattice model simulations using the exact diagonalization method. Scripts for DB generation, and data acquisition tool for the exhaustive calculation are also developed and will be released to the public for anyone to use.

README

COMPARED

About

COMPutation ARchive of Exact Diagonalization (COMPARED) is a database(DB) for quantum lattice model simulations using the exact diagonalization method. Using HΦ, a quantum lattice model solver using the exact diagonalization method, and the supercomputer of the Institute for Solid State Physics (ISSP), exhaustive calculations are performed and the DB is created under a unified data standard. Scripts for the exhaustive calculation, DB generation, and a tool for obtaining information are also included in this repository. The calulation using the exact diagonalization method returns exact results under a specified lattice size and model, thus it is often used as verification data for comparison with other methods. We hope that this DB will be helpful for researchers and students in the field of condensed matter physics.

Usage

  • Install DB

    • Using git

      git clone https://isspns-gitlab.issp.u-tokyo.ac.jp/compared/compared.git

    • Download directly

      wget [URL_to_download_data] -P [Path_to_store_download_data]

  • How to get dataset from DB

    You can get dataset under some conditions from DB using serch_from_h5.py in tools directory by following procedures.

    1. Move to the directory where the DB file (*.h5) is located.

      • Note that some directories does not have the DB files because of the limitation of the storage. If you want to get the missing DBs, please contact us by e-mail (see the last part of this document).

    2. Make symbolic link to search_from_h5.py.

    3. Make an input file (hereafter, refferred to as search.in) for serch_from_h5.py.

    4. Enter the following command.

      python search_from_h5.py search.in
