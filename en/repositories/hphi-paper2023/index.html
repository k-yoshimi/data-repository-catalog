Overview

HΦ is a software package for solving a wide range of quantum many-body problems. This repository provides inputs and outputs introduced in the paper entitled "Update of HΦ: Newly added functions and methods in versions 2 and 3".

About

HΦ is a software package for solving a wide range of quantum many-body problems.

HPhi's official page

This repository provides inputs and outputs introduced in the following paper: K. Ido et. al., "Update of HΦ: Newly added functions and methods in versions 2 and 3", Comput. Phys. Commun. 298, 109093 (2024).
