README

Simulation data of the Rayleigh-Taylor instability

About

This repository contains all the raw data related to the following paper which investigated the Rayleigh-Plateau instability using molecular dynamics simulations.

  • S. Kikuchi and H. Watanabe, "Molecular Dynamics Study of Rayleigh-Plateau Instability at Liquid-Liquid Interfaces", Phys. Rev. Fluid, vol. 11, p. 023901, (2026). – Published 4 February, 2026
  • https://doi.org/10.1103/1m7q-lfwy
  • arXiv:2507.13786

Folder Structure

Each folder name corresponds to the figure number in the paper.

Extentions of files

  • *.dat Data (output) file
  • *.plt Plot file for Gnuplot
  • *.pdf PDF files generated from the data

How to generate figures

You can generate the corresponding plot by running gnuplot in each directory.

For example, executing the following command in the fig/fig12 directory will create fig12.pdf.

cd fig/fig12
gnuplot fig12.plt
