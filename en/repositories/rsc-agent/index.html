README

Snapshot Data for "Building a Research-Software Catalog with a Coding Agent: From Hackathon Prototype to Public Deployment"

Data underlying the paper Building a research-software catalog with a coding agent: from hackathon prototype to public deployment (Yoshimi, Terasaki, Yamada; arXiv:2609.04711, 2026; see Citation). The dataset has two parts, each with its own README:

Directory Contents
catalog-snapshot/ The complete per-record export of the 1 September 2026 build of the research-software catalog (68 public repository records, seven readiness signals and a 0–100 readiness score each), the derived tables behind Figure 4 of the paper, provenance metadata of the generating build, and validation scripts.
materiapps-corpus/ The corpus behind the MateriApps retrieval case study (Section 4): portal metadata of the 336 applications listed on 31 July 2026, the 6,230 crawled documentation pages (crawl completed 3 August 2026), the 49,485-passage vector index, and supplementary generation-quality evaluation runs (not reported numerically in the paper).

Validation

Both checks need Python ≥ 3.11. The catalog check also needs PyYAML (pip install pyyaml); without it the script fails when it reaches the YAML metadata files. Run from the repository root:

python3 catalog-snapshot/scripts/validate_snapshot.py   # prints "Snapshot validation: PASS"
python3 materiapps-corpus/check_corpus.py               # prints "Corpus check: PASS"

The values each script verifies are listed in the README of its directory.
