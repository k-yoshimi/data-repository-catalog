Overview

Using high-throughput calculations based on the density functional theory, we construct a structure map for AB2 type monolayers of 3844 compounds which are all the combinations of 62 elements selected from the periodic table. This database provides data for producing the structure map, the obtained physical properties, input files and so on.

README

Structure map of AB2 type 2D materials by high-throughput DFT calculations

About

Using high-throughput calculations based on the density functional theory,
we construct a structure map for AB2 type monolayers of 3844 compounds
which are all the combinations of 62 elements selected from the periodic table.
This database provides data for producing the structure map,
the obtained physical properties, input files and so on. The structure map is provided as an interactive website linked with a customized version of OpenMX Viewer, which enables us to easily visualize the obtained structures here.

Usage

  • Install Database

    • Using git

      git clone https://isspns-gitlab.issp.u-tokyo.ac.jp/masahiro.fukuda/structure-map-of-ab2-type-2d-materials-by-high-throughput-dft-calculations.git

    • On browser

      Click the download button of this project.

  • Data structure

    • data
      • dat_ini (OpenMX input files for geometrical optimization)
        • code (program codes for generating OpenMX input in C language)
          • gen_struc_1T.c
          • gen_struc_2H.c
          • gen_struc_planar.c
        • 1T
          • cif_1T
        • 2H
          • cif_2H
        • planar
          • cif_planar
      • cif_final (cif format files after geometrical optimization)
        • 1T
        • 2H
        • planar
      • ciflist_primitive (cif format files of primitive cells of structures in cif_final)
      • datband (OpenMX input files for DOS and band structure calculations)
      • all_banddos.tar.gz (figures of bands and DOS)
      • pic (high resolution pictures of structure maps)
      • table_for_structure_map.csv (information of converged structures for drawing the structure map)
