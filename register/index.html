データセットを登録する

ISSP データリポジトリへの登録申込みです。論文の DOI を入力すると、タイトル・著者・ORCID・文献情報を取得して申込フォームに記入した状態で開きます。DOI がない場合は、空のフォームから申し込めます。

登録の流れと条件

  1. このページから申込フォームに記入して送信します。
  2. データリポジトリ担当が内容を確認します。
  3. 受け付けられると、ISSP GitLab にデータ公開用のページ（リポジトリ）が作られます。
  4. そのページの URL と、データを登録・編集するための情報が、連絡先（Contact）のメールアドレスに届きます。

申し込む前に

  • 容量: 10 GB を超える容量が必要な場合は、フォームに希望の容量を書いてください。
  • ライセンス: CC BY 4.0 などのオープンなライセンスを推奨しています。
  • タイトル: 使える文字は英字・数字・絵文字・「_」「.」「-」・空白で、英字か数字で始めます。
  • 書式: About・References・Related software には Markdown が使えます。
  • 連絡先: Contact に書いたメールアドレスは公開ページに掲載されます。

問い合わせ: datarepo__at__issp.u-tokyo.ac.jp（__at__ を @ に置き換えてください）

論文の DOI から入力する

データに対応する論文（またはデータセット）の DOI を入力してください。

DOI の照会には doi.org と OpenAlex を使います。送信されるのは入力した DOI だけです。

DOI なしで申し込む

論文が未発表の場合や、論文に対応しないデータベース・ソフトウェアの場合は、空のフォームからすべての項目を入力して申し込めます。

空の申込フォームを開く ↗ Google フォームが新しいタブで開きます。
