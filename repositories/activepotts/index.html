README

Simulation code and data for active Potts models

======= Code: simulation code for coarsening dynamics C language with sample input files

To generate the figures and movies, gnuplot is required.

Copyright and license The codes and scripts are distributed under GNU GPLv3. The data are distributed under CC-BY 4.0. Copyright 2025, Hiroshi Noguchi
