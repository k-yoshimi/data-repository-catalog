概要

We systematically derive low-energy effective Hamiltonians for molecular solids conductors alpha-ET2I3 and alpha-BETS2I3 with available room- and low-temperature structures using ab initio density functional theory calculations. The effective models are solved using the many-variable variational Monte Carlo method . This repository provides the data including input and output data for ab initio calculations by Quantum ESPRESSO, downfolding by RESPACK, and many-variable variational Monte Carlo methodby mVMC.

README

Ab initio Hamiltonians for molecular solids alpha-ET and alpha-BETS

About

We derive low-energy effective Hamiltonians for molecular solids alpha-ET2I3 and alpha-BETS2I3 with available room- and low-temperature structures using ab initio density functional theory calculations. The obtained effective Hamiltonians are solved using the many-variable variational Monte Carlo method. This repository provides the data including input and output data for ab initio calculations by Quantum ESPRESSO, downfolding by RESPACK, and many-variable variational Monte Carlo calculations by mVMC.
