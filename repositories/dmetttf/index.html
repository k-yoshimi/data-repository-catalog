Dataset for Ab initio study of an organic conductor (DMET-TTF)$2$AuBr$2$

k-yoshimi / dmetttf

電子状態計算（固体物理）強相関電子系・有効模型GnuplotCC BY 4.0 (dataset)
更新: 2023-11-14

概要

The data repository provides a comprehensive dataset related to the theoretical study of an organic conductor (DMET-TTF)$2$AuBr$2$ at high pressures (0-7.61 GPa) analyzed by x-ray diffraction measurements. This repository provides the data, including input and output data for ab initio calculations by Quantum ESPRESSO, and downfolding by RESPACK.
