t-ishikawa / SaclaDenoise

機械学習PythonCC-BY 4.0
更新: 2024-05-01

概要

Single-shot imaging with femtosecond X-ray lasers is a powerful measurement technique that can achieve both high spatial and temporal resolution. However, its accuracy has been severely limited by the difficulty of applying conventional background processing. In this data repository, sample codes, training dataset and learned model for deep learning method which was used to validate noise reduction techniques are provided.

How to use these program

  1. Program operating environment python3, numpy, scipy, tensorflow (or tensorflow gpu)

  2. Padding the simulation data

    Prepare these data and put the same directry

        -add_noise.py
    -triangle.npy
    -w.csv

    Please type the following command: $ python3 add_noise.py

    You can get 2000 noisy-data "x_test.npy" and correct-data "x_test_correct.npy" for validation and 20000 noisy-data "x_train.npy" and correct-data "x_train_correct.npy" for learning. If you want to change the shape or mask data, change the input data in line 17 or line 19, respectively.

  3. Learning process

    Prepare these data and put the same directry

        -unet.py
    -x_train.npy
    -x_train_correct.npy
    -x_test.npy
    -x_test_correct.npy

    Please type the following command:

    $ python3 unet.py

    You can get the parameter "autoencoder.h5" as the learning result, the value "Train_Loss.dat" "Valid_Loss.dat" of the Loss function of the learning process, and 100 correct-images "true_data.npy" noisy-images "noisy_data.npy" decoded-images "decoded_data.npy" for the simulation data not used for learning. If you want to change the model, change the unet.py to other program. If you want to do transfer learning, change "check=0" to "check=1" in unet.py and prepare the learned parameter "autoencoder_data20_epoch50_batch20.h5".

  4. Denoise the experimental data

    Prepare these data and put the same directry

    -denoise_unet.py
-autoencoder_data20_epoch50_batch20.h5
-experimental_data.npy

    Please type the following command: $ python3 denoise_unet.py

    You can get decoded-data "decoded_data.npy". If you want to change the model, change the denoise_unet.py to other program.
