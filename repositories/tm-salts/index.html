Ab initio Hamiltonians for molecular solids TMTTF and TMTSF salts

k-yoshimi / tm-salts

電子状態計算（固体物理）強相関電子系・有効模型CC BY 4.0
更新: 2023-11-10

概要

We systematically derive low-energy effective Hamiltonians for molecular solids conductors TMTTF2X and TMTSF2X (X represents a cation) with available room- and low-temperature structures using ab initio density functional theory calculations. The effective models are solved using the many-variable variational Monte Carlo method . This repository provides the data including input and output data for ab initio calculations by Quantum ESPRESSO, downfolding by RESPACK, and the many-variable variational Monte Carlo method by mVMC.
