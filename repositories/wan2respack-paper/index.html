README

Interface tool from Wannier90 to RESPACK – wan2respack

About

$\tt{wan2respack}$ is the interface tool, which converts Wannier functions in the $\tt{Wannier90}$ format into those used in $\tt{RESPACK}$ (the open-source software package for the derivation of the $ab$ $initio$ low-energy effective Hamiltonians.). This software is distributed under GNU GPL v3.0 and you can download it from the following GitHub page.

https://github.com/respack-dev/wan2respack

This repository includes inputs and outputs of the following paper related with $\tt{wan2respack}$.

K. Kurita, T. Misawa, K. Yoshimi, K. Ido, T. Koretsune, "Interface tool from Wannier90 to RESPACK: wan2respack", Comput. Phys. Commun. 292, 108854.
